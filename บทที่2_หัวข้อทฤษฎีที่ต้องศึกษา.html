บทที่ 2: เอกสาร ทฤษฎี และเทคโนโลยีที่เกี่ยวข้อง

โปรเจกต์: Tab-Lock / ExamPro — ระบบจัดสอบออนไลน์พร้อมระบบคุมสอบผ่านเว็บแอปพลิเคชัน

หัวข้อทฤษฎีที่ต้องศึกษา (Outline)

1. ความรู้พื้นฐานเกี่ยวกับระบบจัดสอบออนไลน์และระบบคุมสอบผ่านเว็บแอปพลิเคชัน

  • 1.1 ทฤษฎีด้านการวัดและการประเมินผลทางการศึกษา (Educational Measurement & Evaluation)
    • 1.1.1 ความหมายและหลักการของการวัดและประเมินผลการเรียนรู้ผ่านสื่อดิจิทัล
    • 1.1.2 รูปแบบการทดสอบแบบปรนัยและอัตนัย (Multiple Choice & Essay Test)
    • 1.1.3 แนวคิดการคุมสอบออนไลน์และการป้องกันการทุจริต (Online Proctoring & Anti-Cheating)
      • 1.1.3.1 ความหมายและรูปแบบของการคุมสอบออนไลน์
      • 1.1.3.2 พฤติกรรมการทุจริตในการสอบออนไลน์ (การสลับแท็บ, การคัดลอก-วาง, การสลับหน้าจอ)
      • 1.1.3.3 เทคนิคการสลับสับเปลี่ยนข้อสอบและตัวเลือก (Question & Choice Randomization)
  • 1.2 ทฤษฎีเนื้อหาหลักและฟังก์ชันการทำงานของระบบ (Core Content & Features)
    • 1.2.1 ระบบจัดการคลังข้อสอบและการจัดชุดข้อสอบ (Question Bank Management)
    • 1.2.2 ระบบจัดการห้องสอบและการควบคุมเวลา (Exam Room & Timer Management)
    • 1.2.3 ระบบการจัดการผู้ใช้งานตามสิทธิ์ (Role-based Access Control: Student, Teacher, Super Admin)
    • 1.2.4 การประมวลผลและการรายงานผลการสอบ (Data Analysis & Export)
  • 1.3 ทฤษฎีด้านระบบและเทคโนโลยี (System & Technology)
    • 1.3.1 การพัฒนาเว็บแอปพลิเคชัน (Web Application Development)
      • 1.3.1.1 สถาปัตยกรรม Client-Server (Client-Server Architecture)
      • 1.3.1.2 รูปแบบการเชื่อมต่อแบบ RESTful API (RESTful API Architecture)
      • 1.3.1.3 ภาษา HTML5 (HyperText Markup Language)
      • 1.3.1.4 ภาษา CSS3 และ Tailwind CSS Framework
      • 1.3.1.5 ภาษา JavaScript (Client-side & Server-side)
      • 1.3.1.6 สภาพแวดล้อมประมวลผล Node.js (Node.js Runtime Environment)
      • 1.3.1.7 เว็บเฟรมเวิร์ก Express (Express.js Framework)
      • 1.3.1.8 การแลกเปลี่ยนข้อมูลด้วยรูปแบบ JSON (JavaScript Object Notation)
    • 1.3.2 การออกแบบส่วนติดต่อผู้ใช้งาน (UI/UX Design)
      • 1.3.2.1 ส่วนติดต่อผู้ใช้งาน (User Interface: UI)
        • แนวคิดและรูปแบบการออกแบบ UI (UI Design Style & Concept)
        • การออกแบบสไตล์กระจกฝ้า (Glassmorphism UI Design)
        • การออกแบบยืดหยุ่นรองรับทุกหน้าจอ (Responsive Web Design)
        • ทฤษฎีสีและจิตวิทยาของสีใน UI (Color Theory in UI)
      • 1.3.2.2 ประสบการณ์ผู้ใช้งาน (User Experience: UX)
        • แนวทางการสร้าง UX สำหรับระบบจัดสอบและคุมสอบออนไลน์
      • 1.3.2.3 หลักการสำคัญในการออกแบบ (Usability Heuristics)
        • หลักการ 10 ข้อของ Nielsen สำหรับการออกแบบส่วนติดต่อผู้ใช้งาน
    • 1.3.3 ไลบรารีเสริมสำหรับการพัฒนา (Supporting Libraries)
      • 1.3.3.1 Chart.js สำหรับการแสดงผลสถิติและกราฟวิเคราะห์ผลสอบ
      • 1.3.3.2 SheetJS (XLSX) สำหรับการนำเข้าและส่งออกข้อมูลผ่านไฟล์ Excel
  • 1.4 ทฤษฎีด้านการประเมินผลระบบ (Evaluation Methodology)
    • 1.4.1 การประเมินคุณภาพซอฟต์แวร์โดยผู้เชี่ยวชาญ (Software Quality Evaluation)
    • 1.4.2 การประเมินความพึงพอใจของผู้ใช้งาน (User Satisfaction - นักศึกษาและอาจารย์)

2. ระบบฐานข้อมูลและอัลกอริทึม

  • 2.1 การจัดการฐานข้อมูลและอัลกอริทึม
    • 2.1.1 หลักการจัดการฐานข้อมูลเชิงสัมพันธ์ (Relational Database Management System: RDBMS)
    • 2.1.2 การใช้งานฐานข้อมูล SQLite3 และ PostgreSQL (Neon Database)
    • 2.1.3 อัลกอริทึมที่ใช้ในระบบ
      • 2.1.3.1 อัลกอริทึมการสุ่มข้อสอบและสลับตัวเลือก (Fisher-Yates Shuffle Algorithm)
      • 2.1.3.2 อัลกอริทึมตรวจจับพฤติกรรมการทุจริต (Tab Switching / Blur Event Listener Algorithm)
      • 2.1.3.3 อัลกอริทึมคำนวณและตัดเกรดคะแนนสอบอัตโนมัติ

3. โปรแกรมและเครื่องมือที่ใช้

  • 3.1 โปรแกรม Visual Studio Code (VS Code) สำหรับเขียนและแก้ไขโค้ด
  • 3.2 เว็บเบราว์เซอร์สำหรับการทดสอบระบบ (Google Chrome, Microsoft Edge, Brave)
  • 3.3 สภาพแวดล้อมประมวลผล Node.js และระบบจัดการแพ็กเกจ npm
  • 3.4 เครื่องมือจัดการฐานข้อมูล (DB Browser for SQLite / Neon Console)
  • 3.5 สคริปต์ Windows Batch Launcher (`.bat`) สำหรับเปิดใช้งานระบบอัตโนมัติ

4. งานวิจัยที่เกี่ยวข้อง

  • 4.1 งานวิจัยด้านการพัฒนาระบบการทดสอบออนไลน์ (Online Examination Systems)
  • 4.2 งานวิจัยด้านการตรวจจับและป้องกันการทุจริตในการสอบออนไลน์ (Online Exam Proctoring & Anti-Cheating)
  • 4.3 งานวิจัยด้านการประเมินประสิทธิภาพและความพึงพอใจในการใช้งานเว็บแอปพลิเคชันทางการศึกษา

🎨 สรุปทฤษฎีสีและการออกแบบ (สำหรับเขียนอธิบายในเล่ม)

จิตวิทยาของสี:

  • Cyan #06b6d4 ความน่าเชื่อถือ ความมั่นคง ปลอดภัย ความเที่ยงตรง
  • Violet #8b5cf6 นวัตกรรม เทคโนโลยี และความฉลาด
  • Emerald Green #10b981 ความสำเร็จ การเปิดใช้งาน และการดำเนินการเรียบร้อย
  • Rose Red #dc2626 การแจ้งเตือน การเตือนความเสี่ยง และการทุจริต

กฎ 60-30-10 & Style:

  • 60%: สีขาว/สว่างโปร่งแสง (Background Glassmorphism)
  • 30%: สี Slate/Navy (#1e293b) สำหรับตัวหนังสืออ่านง่าย
  • 10%: สี Gradient Accent สำหรับปุ่มและจุดดึงดูดสายตา
  • Glassmorphism: สไตล์กระจกฝ้าโปร่งแสง backdrop-filter: blur(24px)
  • Responsive Design: ปรับเปลี่ยนขนาดเลย์เอาต์หน้าจออัตโนมัติบนทุกอุปกรณ์
